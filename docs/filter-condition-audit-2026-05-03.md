# 条件搜索与账号在线审查（2026-05-03）

## 本轮结论

- 账号管理卡顿和筛选项异常的直接原因：前端账号管理页复用了订单列表的通用搜索栏，导致展示了订单列表的条件项，而不是账号管理自己的筛选项。
- 已改为账号管理专属筛选栏：账号/姓名、角色、状态、是否在线。
- 后端 `/users` 已支持 `keyword` 同时匹配账号和姓名，并新增 `status`、`is_online` 条件。
- 账号在线可见规则已调整为：只要当前账号具备账号列表查看权限，就能在账号管理中看到自己权限范围内下级账号是否在线。
- 数据库字段未修改，前端布局样式未修改，只调整查询逻辑、接口参数和权限能力标识。

## 权限与范围

- 超级账号：可查看经理、业务、财务、市场等可管理账号，账号列表返回在线状态。
- 经理账号：可查看自己创建且在所属团队范围内的业务、财务、市场账号，账号列表返回在线状态。
- 业务/财务/市场账号：默认无账号管理入口和账号列表查看能力，不额外暴露在线信息。
- 在线判定沿用后端会话窗口：最近活跃且未过期的 `user_session_new` 记录视为在线。

## 条件搜索覆盖

- 账号管理：账号/姓名、角色、状态、是否在线。
- 客户管理：客户编码、客户名称、市场、区域、创建人、是否包含已删除。
- 渠道管理：渠道编码、渠道名称、区域、创建人、是否包含已删除。
- 全部订单/已完成/未完成订单：创建日期、渠道、客户、业务员、团队、车主、身份证、车牌、发动机号、车架号、车型、备注、完成状态。
- 财务列表：创建日期、渠道、客户、市场、团队、车主、保险到期日、初登日期、是否回款、是否返点。
- 财务汇总：复用财务列表同一组筛选条件，单独验证 `/finance/orders/summary` 请求成功。
